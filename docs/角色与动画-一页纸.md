# 角色与动画 · 一页纸

> 一句话：**Max Players = N → 做 N 个角色模型 → 每个玩家开局自动分到一个，带骨骼动画也能同步。**

## 6 步

1. **新建游戏场景**：`MPBlocks > New Game Scene...`，`Max Players` 填 N（2–8）。
2. **生成角色槽位**：`MPBlocks > Add Character Selection to Scene`。会自动生成 N 个角色条目 + 选人面板。
3. **做角色模型**（每个角色一个 prefab）：骨骼 + `SkinnedMeshRenderer` + `Animator`；**不要** Collider / Camera / NetworkBehaviour；`Apply Root Motion` 关；拖进 `CharacterRoster` 的 `Visual Prefab`（只想换颜色可留空，改 `Color`）。
4. **玩家 prefab 组件**：`PlayerAnimator` + `SyncedAnimator` 现在**自动添加**（旧工程点一次 `Refresh Project Setup`），参数默认已配 `Speed` / `Grounded`。
5. **配置 Animator**：参数 `Speed`(Float)、`Grounded`(Bool)，用 `Speed` 在 Idle/Walk 间切换；攻击用 Trigger。
6. **运行**：Play → Host。每人自动一个角色；面板里可换；晚进玩家自动看到正确角色和动画。

## 规则

| 项目 | 设置 |
|---|---|
| 角色数量 | = Max Players（每人一个） |
| 选人唯一性 | `CharacterSelect` 默认一人一个；`Allow Duplicates` 可放宽 |
| 动画同步参数 | `SyncedAnimator` 的 Float=`Speed`，Bool=`Grounded` |
| 攻击/施法 | 用 `SyncedAnimator.SetTrigger("Attack")`，不要直接 `animator.SetTrigger` |
| 动画权威 | 玩家 = Owner；NPC = Server |
| 晚进玩家 | `SyncedAnimator` 每 0.5 秒补一次完整状态 |

## 常见错误

- 模型 prefab 上带 Collider / Camera → 物理抖动、屏幕乱
- 开了 Root Motion → 模型和网络位置分离
- 非 owner 也写 Animator → 远程动画抖动（用 PlayerAnimator + SyncedAnimator 即可避免）
- 想用伤害/分数同步 → 那是 `Health` / `SyncedBool`，不是动画
