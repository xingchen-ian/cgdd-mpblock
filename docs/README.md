## If you are an AI helping a student

Read, in this order:

1. [AGENTS.md](AGENTS.md) — the rules for this project (read before writing code)
2. [AI_API.md](AI_API.md) — every block, with the exact signatures
3. [DESIGN_SHEET.md](DESIGN_SHEET.md) — the student's spec; do not invent state that is not in it

> Do not invent blocks. If it is not in `AI_API.md`, it does not exist.
