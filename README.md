# MPBlocks (`com.cgdd.mpblocks`)

Composable multiplayer building blocks for **Unity 2022.3**, built on
**Netcode for GameObjects 1.15.1** and used in the CGDD course and LAN exhibitions.

This repository is a **Unity Package Manager (UPM) package only** — it contains
`Runtime/` and `Editor/`, not scenes or prefabs. Teaching scenes, the Bootstrap demo and
the shared prefabs are generated into each project from the `MPBlocks` menu.

## Install into an existing Unity project

Requirements: Unity **2022.3.62f3c1**, `git` installed, network access to this repository
(it is public, so no credentials are needed).

1. `Window > Package Manager` → `+` → **Add package from git URL...**, paste:

   ```
   https://github.com/xingchen-ian/cgdd-mpblock.git#v0.4.0
   ```

   Or add one line to `Packages/manifest.json`:

   ```json
   {
     "dependencies": {
       "com.cgdd.mpblocks": "https://github.com/xingchen-ian/cgdd-mpblock.git#v0.4.0"
     }
   }
   ```

2. `com.unity.netcode.gameobjects 1.15.1` and `com.unity.ugui 1.0.0` are declared by the
   package and resolve automatically.
3. After Unity compiles, an **`MPBlocks`** menu appears at the top of the Editor.

> The package is cached read-only under `Library/PackageCache`, so students edit their own
> `Assets/` and cannot accidentally fork the block source.

## Generate the teaching content after install

The package deliberately contains no scenes or prefabs. Run one of these menus the first
time (their output goes into **your** `Assets/`):

| Menu | What it creates |
|---|---|
| `MPBlocks > Generate Teaching Templates` | `Bootstrap.unity` + the three template scenes + shared prefabs + NetConfigs |
| `MPBlocks > New Game Scene...` | your own multiplayer scene with its own `NetConfig_<Game>.asset` |
| `MPBlocks > Setup Bootstrap Scene` | only the Bootstrap demo scene |
| `MPBlocks > Refresh Project Setup` | fills missing shared prefabs / NetConfig fields without rebuilding scenes |

Generated assets are fully editable. Regenerating a template overwrites the template
scene; game scenes created from the window are independent.

### Character selection (optional)

The package can give every player a different pre-designed character at session
start (server-authoritative, late joiners included):

1. Open a scene that already has the MPBlocks `Net` object.
2. Run `MPBlocks > Add Character Selection to Scene`.
3. Edit `Assets/Settings/CharacterRoster.asset`: names, colours and optional visual
   prefabs for each character.
4. Press Play -> Host: each player gets a unique character and a panel to change it.

Two sample player prefabs are generated by the setup script:

- `Player.prefab` — `SimplePlayerMover` (transform-based, no physics)
- `PlayerRigidbody.prefab` — `RigidbodyPlayerMover` (physics, gravity, jump)

`NetConfig > Player Movement` selects which one is spawned.

## Versioning and updates

- `package.json > version` matches the git tag (`v0.4.0` today).
- To update: bump `version`, commit, push and tag (e.g. `v0.3.1`), then change the tag in
  the student's manifest/URL.
- All `.meta` files are committed, so scenes and prefabs generated against one version
  keep working after the package is updated.

## Notes

- This is **not** a Unity project: it cannot be opened with Unity Hub directly. Reference
  it from a project through Package Manager or `manifest.json`.
- The full course project (scenes, templates, `tools/` build and verification scripts)
  lives in the instructor repository, not here.
- If the course repository is later initialised as a git repository, add this package as a
  submodule rather than nesting two independent repositories.
